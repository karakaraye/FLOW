## Tenant and integration review

Workspace API entrypoints use the shared authenticated membership wrapper with same-origin mutation checks, current role checks, UUID validation and bounded JSON. Root workspace lookup was moved to the same wrapper. Workflow/version/run lookups bind workspace identifiers; publishing has a database immutability trigger. Workers use current membership and credential binding, not the supplied workspace ID alone. Service-side transaction locks and composite relationships guard resource races. Tests cover all role classes and foreign workspace access, including billing, AI, WhatsApp and credentials/events. Internal worker/operations maintenance is privileged, server-only and never accepts arbitrary browser tenant scope. The operations token grants aggregate cross-tenant metrics deliberately; ordinary workspace owners cannot access it.

Google OAuth retains one-time state, exact redirect/origin binding, PKCE/scopes and encrypted refresh tokens. Callback logging excludes query strings. WhatsApp and Paystack preserve raw-body signature verification and replay/event deduplication. HTTP action DNS/IP/TLS/redirect restrictions remain enforced; the deployment example does not add an SSRF bypass. AI retains model/input/output limits, budget reservation and uncertain-cost accounting. Disabled/revoked integrations are checked at execution and cannot authorize new effects. External operations preserve prior sent/unknown fences rather than promising exactly-once delivery. Existing real-worker fixture tests exercise these paths; no actual live provider has been activated.

Auth uses Better Auth database sessions, explicit trusted origin, HttpOnly SameSite=Lax cookies (Secure on HTTPS), bounded lifetime/freshness, database-backed rate limiting and no session cache. Production signup is closed. Same-origin enforcement supplements Better Auth CSRF rather than disabling it. API errors and request logs intentionally avoid raw exception/provider payloads. Platform/database/framework logs still require operational review.

The controls reduce identified risk; they do not prove all conceivable cross-tenant defects absent. Required staging and public-auth work prevent an unconditional production-readiness verdict.
